# الدخول الموحّد من الموقع الأم (المرحلة الثانية)

يضغط الموظّف «مكتبة المرئيات» في `wallt.emdatra.org`، فتُفتح المكتبة في نافذة جديدة (`window.open`، لا iframe)
وهو داخل. لا كلمة مرور ثانية، ولا نسخ لقائمة المستخدمين.

## كيف يعمل
1. **الموقع الأم** يصنع رابطًا قصير العمر لحظة الضغط:
   `https://media.emdatra.org/api/auth/sso?u=…&e=…&n=…&r=…&exp=…&nonce=…&sig=…`

   | الحقل | المعنى |
   |---|---|
   | `u` | معرّف المستخدم في الموقع الأم |
   | `e` | بريده |
   | `n` | اسمه |
   | `r` | دوره في المكتبة: `admin` أو `photographer` أو `editor` أو `contributor` |
   | `exp` | الآن + 60 ثانية (المكتبة ترفض ما يتجاوز 120 ثانية) |
   | `nonce` | 16 بايتًا عشوائيًا (base64url) |
   | `sig` | `HMAC-SHA256(secret, "media-sso|v1|u|e|n|r|exp|nonce")` بصيغة hex |

2. **المكتبة** تتحقّق بالترتيب:
   - الشكل.
   - التوقيع، بمقارنة ثابتة الزمن.
   - الوقت.
   - الدور.
   - ثم تستهلك `nonce`، فلا يعمل الرابط مرتين.
3. **المستخدم:**
   - يُعرف بـ `u`. وإن وُجد حساب محلي بالبريد نفسه رُبط به مرة واحدة.
   - وإلا أُنشئ حساب بلا كلمة مرور.
   - **الاسم والبريد والدور يُحدَّثان في كل دخول**، فالموقع الأم هو المرجع: تخفيض دور هناك تخفيض هنا. والحساب
     الموقوف في المكتبة يُرفض.
4. **أي رفض** يعود إلى صفحة الدخول ومعه سببه مكتوبًا: انتهت الصلاحية، استُعمل من قبل، توقيع غير صحيح، دور غير
   مسموح، حساب موقوف.

**الحساب المربوط** يدخل من الموقع الأم أو برابط البريد، وتتوقّف كلمة مروره المحلية القديمة عن العمل. هذا مقصود:
باب واحد يديره الموقع الأم.

## التفعيل
1. سرّ مشترك بطول 32 حرفًا على الأقل: `openssl rand -base64 48`.
2. **في المكتبة** (`/opt/sites/media/.env`): `EMDATRA_SSO_ENABLED=true` و`EMDATRA_SSO_SECRET=…`، ثم إعادة
   تشغيل `media-app`.
3. **في الموقع الأم:** السرّ نفسه في `config.php` بالثابت `MEDIA_SSO_SECRET`، والدالّة أدناه.

حتى يتمّ ذلك يردّ `/api/auth/sso` بـ 404، كأنه غير موجود.

## الدالّة في الموقع الأم (PHP)

```php
/** رابط دخول المكتبة لمستخدم الجلسة الحالية — يُصنع لحظة الضغط ولا يُخزَّن. */
function mediaSsoUrl(array $user, string $role) {
    $c = [
        'u' => (string)$user['id'],
        'e' => strtolower(trim($user['email'])),
        'n' => trim($user['name']),
        'r' => $role, // admin | photographer | editor | contributor
        'exp' => (string)(time() + 60),
        'nonce' => rtrim(strtr(base64_encode(random_bytes(16)), '+/', '-_'), '='),
    ];
    $payload = implode('|', ['media-sso', 'v1', $c['u'], $c['e'], $c['n'], $c['r'], $c['exp'], $c['nonce']]);
    $c['sig'] = hash_hmac('sha256', $payload, MEDIA_SSO_SECRET);
    return 'https://media.emdatra.org/api/auth/sso?' . http_build_query($c);
}
```

## الاختبار
- `tests/unit/sso.test.ts`:
  - المتّجه المشترك.
  - تغيير أي حقل يكسر التوقيع.
  - الوقت المنتهي، والوقت البعيد.
  - الدور غير المسموح.
  - المدخلات المشوّهة.
- `tests/e2e/sso.spec.ts`:
  - إنشاء حساب ووصوله إلى صفحته.
  - رفض إعادة الاستعمال.
  - تحديث الدور والاسم من الموقع الأم.
  - ربط الحساب المحلي مرة واحدة.
  - خمسة أسباب للرفض، كلٌّ ظاهر على الشاشة.
