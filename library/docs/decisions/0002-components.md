# 0002 — المكوّنات: React Aria Components مباشرة بأنماط من tokens.css

- **السياق:** الخطة تقول «shadcn/ui على React Aria».
- **ما قسته:** shadcn مولّد نسخ للصق مكوّنات مبنيّة على Tailwind؛ نسخته على React Aria (jolly-ui) تأتي بألوان وزوايا Tailwind الافتراضية التي يجب نزعها كلها لمطابقة `tokens.css` وقاعدة «لا ألوان من خارج الرموز».
- **القرار:** نأخذ الجوهر (React Aria Components للسلوك والوصولية وRTL) ونكتب الأنماط مرة واحدة بوحدات CSS تقرأ الرموز وحدها. النتيجة نفس فكرة shadcn (الشيفرة ملكنا داخل المستودع) بلا طبقة Tailwind.
