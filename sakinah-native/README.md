# سكينة — التطبيق الأصلي (Swift / SwiftUI)

إعادة بناء «سكينة» تطبيقًا أصليًا ١٠٠٪ لنظام iOS (ثم Android بـ Kotlin بالبنية نفسها)، مع إبقاء النسخة الهجينة الحالية على TestFlight حتى يبلغ الأصلي التكافؤ.

## البنية
- `Sources/SakinahCore/` — النواة: منطق خالص بلا واجهة (Foundation فقط)، يُبنى ويُختبر على Linux وmacOS ويُستخدم من iOS وwatchOS:
  - `Astro.swift` (فلك Meeus)، `PrayerTimes.swift` + `Methods.swift` (المواقيت وطرق الهيئات، خطوط العرض العالية، الحل القطبي، رمضان)، `Hijri.swift` (أم القرى عبر ICU + بديل جدولي)، `Qibla.swift` (دائرة عظمى + Vincenty + التحقق بالشمس)، `Geomag.swift` (WMM2025).
- `Tests/SakinahCoreTests/` — اختبارات **المرجع الذهبي**: `Fixtures/golden.json` مولَّد من محرك نسخة الويب (المُتحقَّق منه ضد adhan-js وAlAdhan) بـ `node sakinah-native/tools/export-golden.mjs`؛ النواة الأصلية تُطابقه رقمًا برقم (756 حالة مواقيت، 480 هجري، قبلة، مغناطيسية…).
- `App/` — تطبيق iOS بـ SwiftUI (iOS 17+). المشروع يُولَّد من `project.yml` بـ XcodeGen ولا يُلتزَم `.xcodeproj`.

## البناء
```sh
cd sakinah-native && swift test                 # النواة (Linux/macOS)
cd App && xcodegen generate && open Sakinah.xcodeproj   # التطبيق (macOS/Xcode 16)
```
TestFlight: الدفع إلى فرع `sakinah-native-ios` في مستودع wilt يشغّل `sakinah-native-ios.yml` (معرّف الحزمة `org.emdatra.sakinah.native`).

## خارطة الطريق
1. **الأساس** ✓: النواة + المرجع الذهبي + المواقيت والقبلة والإعدادات + CI وTestFlight.
2. **الصلاة كاملة** ✓ (عدا الودجت): إشعارات النظام بصوت الأذان (أقرب 60 موعدًا، تُجدَّد عند كل فتح)، الأذان الكامل داخل التطبيق، اختيار المدن دون اتصال (649 مدينة)، الجدول الشهري وتصدير ICS. المتبقي: Live Activity وودجت شاشة القفل (يحتاج امتداد WidgetKit ومجموعة تطبيقات وملف provisioning ثانيًا).
3. **المصحف** ✓: صفحات المدينة الـ604 بخطوط الصفحات المضمّنة مضغوطة (`tools/build-fonts.py`)، مفكّك التخطيط في النواة مطابق لمحرّك الويب، التقليب الأفقي/الرأسي، فهرس وبحث موحّد (صفحة/مرجع/سورة/نص)، وضع النص المتدفق (أميري قرآن/حفص) بالتجويد الملوّن وحجم الخط والتباعد، 16 سمة، قائمة الآية (التفسير الميسّر المضمّن، الاستماع، العلامات بملاحظة ولون، المشاركة نصًا وصورة)، مشغّل التلاوة (21 قارئًا، تظليل الكلمة بتوقيتات quran.com، تكرار، سرعة، مؤقت نوم، شاشة القفل، تنزيلات دون اتصال)، مراجعة الحفظ بالتعرّف على الكلام والإخفاء آيةً آية، خطة الختمة وتحدّيات القراءة وخريطة الحرارة، حفظ آخر موضع.
4. **الأذكار والحديث** ✓: أذكار الصباح والمساء بعدّاد يومي محفوظ، حصن المسلم كاملًا (132 بابًا، بحث، مفضلة، تلاوة عند الطلب)، المسبحة بإحصاء اليوم والإجمالي، مختارات الصحيحين والأربعون النووية (تصنيفات، مفضلة، بحث، حديث اليوم)، بطاقات المشاركة بأربع سمات، تذكيرات الأذكار وحديث اليوم وورد الختمة.
5. **النسخ الاحتياطي** ✓ والإحلال: تصدير/استيراد بصيغة نسخة الويب نفسها (تنقل الإعدادات والعلامات والختمة والمسبحة بين النسختين)، لقطات يومية في مجلد المستندات. المتبقي: التعرّف على التلاوة دون اتصال تحسينًا، وإحلال التطبيق الأصلي محلّ الهجين على TestFlight (قرار تبديل معرّف الحزمة).
6. **Android** بـ Kotlin/Compose بالبنية نفسها والمرجع الذهبي نفسه.
