# سكينة — تطبيق مواقيت الصلاة والقبلة والأذكار والأحاديث

تطبيق ويب تقدمي (PWA) عربي يعمل على الهاتف والحاسوب، ويُثبَّت على الشاشة الرئيسية ويعمل دون اتصال. لا يحتاج إلى خادم أو قاعدة بيانات: ملفات ثابتة تُرفع على أي استضافة (مثل cPanel) وتعمل مباشرة.

## المزايا

| الميزة | التفاصيل |
|---|---|
| **مواقيت الصلاة** | حساب فلكي (خوارزميات Jean Meeus) لموقع المستخدم، مع 23 طريقة حساب رسمية (أم القرى، رابطة العالم الإسلامي، الهيئة المصرية، الأوقاف الأردنية، الكويت، قطر، دبي، ديانت تركيا، ISNA، كراتشي، JAKIM…)، اختيار تلقائي للطريقة حسب الدولة، مذهبا العصر، قواعد خطوط العرض العالية، حلّ المناطق القطبية، تعديلات يدوية بالدقائق، تقريب رسمي، منتصف الليل والثلث الأخير، جدول شهري، وتاريخ هجري بتقويم أم القرى. |
| **اتجاه القبلة** | اتجاه جيوديسي على مجسّم WGS‑84 (Vincenty) والمسافة إلى الكعبة، بوصلة حيّة مع **تصحيح الانحراف المغناطيسي** من النموذج المغناطيسي العالمي **WMM2025** (مستشعرات iOS وAndroid تعطي الشمال المغناطيسي فقط)، مؤشر دقة المستشعر، والتحقق المستقل عن البوصلة **بالشمس**: لحظة كون الشمس في اتجاه القبلة، ولحظة إشارة الظل إليها، وموعدا تعامد الشمس على الكعبة. |
| **أذكار الصباح والمساء** | 24 ذكرًا من «حصن المسلم» بنصوصها المشكولة وتخريجها وفضلها، مع عدّاد لكل ذكر، حفظ تقدّم اليوم، اختيار الفترة تلقائيًا من مواقيت الصلاة. |
| **أحاديث مختارة** | أحاديث من صحيحي البخاري ومسلم بمتون منقولة حرفيًا ومُتحقَّق منها آليًا مقابل نصوص الصحيحين (ترقيم فتح الباري / عبد الباقي)، مع الراوي والدرجة والفائدة، حديث اليوم، بحث، تصنيفات، ومفضّلة. |
| **التذكير بالصلاة** | إشعارات بتوقيت المستخدم المحلي عند كل صلاة (وتذكير مسبق اختياري) مع نغمة واهتزاز، وتصدير المواقيت مع منبّهات إلى تقويم الهاتف (ICS) للتذكير حتى مع إغلاق التطبيق. |

الواجهة عربية RTL بالكامل، بسمة فاتحة وداكنة، وأرقام عربية أو لاتينية، ونظام 12/24 ساعة.

## هيكل المشروع

```
sakinah/
├── index.html                ← هيكل التطبيق
├── manifest.webmanifest      ← بيانات التثبيت (PWA)
├── sw.js                     ← عامل الخدمة: عمل دون اتصال + إشعارات
├── .htaccess                 ← إعدادات Apache/cPanel (HTTPS، أنواع الملفات، الكاش)
├── css/app.css               ← نظام التصميم
├── js/
│   ├── app.js                ← الحالة المشتركة والتنقل والمؤقّتات
│   ├── core/                 ← حسابات صرفة (تعمل في المتصفح وNode)
│   │   ├── astro.js          ← موقع الشمس (Meeus)
│   │   ├── prayer-times.js   ← محرك المواقيت
│   │   ├── methods.js        ← طرق الحساب والافتراضي لكل دولة
│   │   ├── qibla.js          ← القبلة: كروي + Vincenty + التحقق بالشمس
│   │   ├── geomag.js         ← WMM2025 (الانحراف المغناطيسي)
│   │   └── hijri.js          ← التاريخ الهجري (أم القرى عبر ICU)
│   ├── platform/             ← واجهات المتصفح: الموقع، البوصلة، الإشعارات، التخزين
│   ├── data/                 ← الأذكار، الأحاديث، المدن
│   └── ui/                   ← الشاشات والمكوّنات
├── tests/                    ← اختبارات node:test + اختبار دخاني بالمتصفح
└── tools/make-icons.mjs      ← توليد الأيقونات
```

## النشر على cPanel

1. ارفع محتويات مجلد `sakinah/` إلى المجلد المطلوب (مثل `public_html/sakinah/` أو نطاق فرعي).
2. تأكد من تفعيل **HTTPS** (شهادة SSL من cPanel): تحديد الموقع والبوصلة والإشعارات لا تعمل إلا على HTTPS.
3. ملف `.htaccess` المرفق يضبط نوع `.webmanifest` ويمنع تخزين `sw.js` في الكاش ويعيد التوجيه إلى HTTPS.
4. افتح الرابط من الهاتف واختر «إضافة إلى الشاشة الرئيسية».

لا يلزم PHP ولا قاعدة بيانات. عند تحديث الملفات غيّر قيمة `VERSION` في `sw.js` ليحصل المستخدمون على النسخة الجديدة.

## التشغيل محليًا والاختبارات

```bash
cd sakinah
npm install            # يثبّت adhan وgeomagnetism (للاختبارات فقط)
npm run fetch-corpus   # (اختياري) تحميل نصوص الصحيحين المرجعية (18 م.ب) لتشغيل اختبار مطابقة الأحاديث حرفيًا
npm test               # اختبارات الوحدات والبيانات (تُتجاوز مطابقة الأحاديث تلقائيًا إن لم تُحمَّل النصوص)
npm run test:e2e       # اختبار دخاني في Chromium (يتطلب playwright)
npx http-server . -p 8080   # ثم افتح http://localhost:8080
```

ملفات التحقق المرجعية الصغيرة (نص حصن المسلم الرسمي وقيم NOAA لاختبار WMM2025) محفوظة في `tests/fixtures/`.

### نسخة تجريبية في ملف واحد

`npm run build:standalone` يولّد `dist/sakinah-standalone.html`: التطبيق كاملًا (CSS وJS والبيانات) في ملف HTML واحد يُفتح مباشرة في المتصفح دون خادم، للتجربة السريعة أو المشاركة. هذه النسخة لا تحتوي عامل الخدمة (لا عمل دون اتصال ولا تثبيت)، والنسخة الكاملة للنشر هي مجلد التطبيق نفسه.

## ضمانات الدقة

- **المواقيت**: مطابقة تامة (إلى الدقيقة) مع مكتبة `adhan` المرجعية في أكثر من 14 ألف مقارنة عبر 20 موقعًا و10 تواريخ و12 طريقة ومذهبين وثلاث قواعد لخطوط العرض العالية، ومقارنة مستقلة مع خدمة AlAdhan ضمن دقيقتين. يُراعى اليوم المدني للمنطقة الزمنية حتى في المناطق التي يخالف توقيتها خط طولها (ساموا، كيريباتي)، ويُعرض عشاء الليلة السابقة إن وقع بعد منتصف الليل في خطوط العرض العالية.
- **القبلة**: الحل الكروي مطابق لـ `adhan`، وVincenty متماثل ويعطي المسافات المعروفة؛ لحظات الشمس محسوبة بدقة ثانية، وحادثتا التعامد تطابقان المواعيد المرصودة (27/28 مايو 09:18 UTC و15/16 يوليو 09:27 UTC).
- **الانحراف المغناطيسي**: WMM2025 مُختبر مقابل قيم NOAA الرسمية.
- **البوصلة**: وُثّق من شفرة WebKit وChromium أن `webkitCompassHeading` و`deviceorientationabsolute` مرجعهما الشمال **المغناطيسي**، لذا يُضاف الانحراف مرة واحدة فقط، مع تعويض دوران الشاشة.
- **الأحاديث**: كل متن يُتحقق آليًا أنه موجود حرفيًا (بلا اعتبار للتشكيل) في نص الحديث المرقّم من الصحيحين.
- **الأذكار**: كل نص يُتحقق آليًا أنه مطابق لنص «حصن المسلم».

## حدود معروفة

- إشعارات المتصفح تعمل ما دام التطبيق مفتوحًا أو في الخلفية؛ لا تسمح المتصفحات بجدولة إشعارات مستقبلية دون خادم دفع. تصدير ICS هو الحل المضمون حين يكون التطبيق مغلقًا، ويمكن لاحقًا إضافة Web Push عبر خادم.
- التقويم الهجري من ICU (أم القرى) قد يختلف يومًا عن إعلان الرؤية المحلي؛ يوجد تعديل ±يومين في الإعدادات.
- اسم الموقع دون اتصال هو أقرب مدينة من القائمة المضمّنة (تُستخدم خدمة جيوكود عكسي مجانية عند توفر الإنترنت).
