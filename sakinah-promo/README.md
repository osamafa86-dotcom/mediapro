# إعلان سكينة — فيديو ترويجي (Remotion)

فيديو ترويجي مدته نحو ٤٦ ثانية بتعليق صوتي عربي، مبني بالكود من لقطات التطبيق الحقيقية وهويته البصرية
(أخضر «الليل» والذهبي، خط Reem Kufi للعناوين وReadex Pro للنصوص، وخط مصحف المدينة للآية).

| النسخة | المقاس | الاستخدام |
| --- | --- | --- |
| `renders/sakinah-promo-vertical.mp4` | 1080×1920 | ريلز إنستغرام، تيك توك، شورتس، ستوري |
| `renders/sakinah-promo-wide.mp4` | 1920×1080 | يوتيوب، الموقع، العروض |
| `renders/cover-vertical.png` | 1080×1920 | غلاف الريلز والستوري |
| `renders/cover-wide.jpg` | 1280×720 | الصورة المصغّرة على يوتيوب |

## الصوت

- **التعليق الصوتي**: ElevenLabs، صوت «Mohammed Ali» (عربية فصحى هادئة)، نموذج eleven_v4. التسجيل الكامل
  في `public/audio/vo/take.mp3`، و`scripts/vo_build.py` يقطعه عند فترات الصمت ويضع كل جملة في مشهدها
  ويعيد ضبط مدد المشاهد في `src/timeline.json` لتتسع لها؛ ومواعيد البطاقات في `src/vo.json` تتبع الكلام.
- **المؤثرات** بلا موسيقى ولا آلات: سرير هواء خافت، «ووش» يتبع اتجاه الانتقال، ضربة منخفضة تحت الشعار
  والختام، ورنّات ونقرات قصيرة. تنخفض ٩ ديسيبل تحت الصوت.
- `scripts/make_audio.py` يمزج المسارين إلى `public/audio/soundtrack.wav` بجهارة نحو −16 LUFS وقمة −1 dBFS.

لتسجيل جديد: ضع ملف mp3 الجديد مكان `take.mp3` بالجمل نفسها مفصولة بوقفات، ثم:

```bash
python3 scripts/vo_build.py && python3 scripts/make_audio.py && npm run render
```

نسخة المؤثرات وحدها بلا تعليق: `python3 scripts/make_audio.py --no-vo` يكتب `public/audio/soundtrack-sfx.wav`
ثم يُركَّب على الفيديو بـ`-map 0:v -map 1:a -c:v copy`. ونسخة بلا صوت إطلاقًا تُستخرج دون إعادة ترميز:

```bash
npx remotion ffmpeg -i renders/sakinah-promo-vertical.mp4 -c:v copy -an renders/sakinah-promo-vertical-silent.mp4
```

## التعديل والإخراج

```bash
npm i
npm run dev                         # Remotion Studio للمعاينة والتعديل
pip install numpy scipy && python3 scripts/make_audio.py   # بعد تغيير التوقيتات
npm run render                      # النسختان إلى renders/ (H.264، BT.709)
```

- النصوص والمزايا في `src/SakinahPromo.tsx`، والمدد ونوع كل انتقال في `src/timeline.json` (غيّرها ثم أعد توليد الصوت).
- الانتقالات: «دفع صفحة» من اليسار إلى اليمين بين المزايا كتقليب المصحف، و«تسليم» هادئ حول الآية والختام (`src/components/transitions.tsx`).
- اللقطات في `public/shots/` (من `sakinah-native/store/screenshots/ar-SA`، مصغّرة إلى عرض 1100).
- في بيئة بلا Chrome Headless Shell مثبّت: أضف `--browser-executable=<مسار headless_shell>`.

**الصوت**
- التعليق: ElevenLabs، نموذج eleven_v4، صوت «مازن»، بنص مشكول بالكامل ونطق الاسم /saˈkiːna/. التسجيل الكامل
  `public/ad30/vo/take.flac`، ويقطعه `scripts/ad30_build.py` إلى ١٢ عبارة (الجدول `PHRASES`).
- التلاوة: `scripts/ad30_quran.py` يأخذ ملف الآية كاملة (1735.mp3)، ويقصّ ما بعد الوقف على «بذكر الله ۗ»،
  ويكتب `public/ad30/quran/13-28.json` بحدود المقطع ومواضع الكلمات. إلى أن يوضع الملف يُحجز للآية مكان صامت.
- المؤثرات: ElevenLabs Sound Effects (eleven_text_to_sound_v2) في `public/ad30/sfx/`، لا موسيقى ولا آلات:
  ضجيج الإشعارات، ضربتان منخفضتان للشعار والختام، «ووش» للانتقالات، طيور الفجر وهواء الظهيرة وصراصير الغروب،
  اهتزاز الإشعار، نقرات البوصلة، صفحة المصحف، حبّات المسبحة، وتبدّد الإعلان.
- `scripts/ad30_build.py` يبني الخط الزمني من مدد العبارات والتلاوة (`src/ad30/timeline.json` و`cues.json`)
  ثم يمزج `public/ad30/soundtrack.wav`: −14 LUFS، وقمة حقيقية ≤ −1 dBTP، والأسرّة تنخفض ٦ dB تحت الكلام.

```bash
pip install numpy scipy soundfile
python3 scripts/ad30_quran.py ~/Downloads/1735.mp3   # مرة واحدة عند وصول التلاوة
python3 scripts/ad30_build.py                         # الخط الزمني + المزج
npx remotion render SakinahAd30 renders/sakinah-ad30-vertical.mp4 --crf=17 --color-space=bt709 --pixel-format=yuv420p --audio-bitrate=256k --jpeg-quality=95
```
